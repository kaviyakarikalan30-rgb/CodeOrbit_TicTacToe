## Project Description
This project is a Tic-Tac-Toe game developed using Python.
The user plays against the computer. The computer uses simple AI
rules to make its moves.

## Features
- User vs Computer gameplay
- Simple AI opponent
- Displays the game board after every move
- Detects player win
- Detects computer win
- Detects draw
- Handles invalid input
- Prevents selecting an occupied position

## Technologies Used
- Python
- If-else conditions
- Functions
- Lists
- Random module

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python tictactoe.py

## Game Symbols

X - Player
O - Computer

## Example

You: 1
Computer is thinking...

The computer automatically selects its move.
